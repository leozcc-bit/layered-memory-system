# notes/ 细节层

每条工作线一个文件，装三类东西：

1. **背景与细节** —— 不适合进规则层（不恒定）、不适合进状态层（太长）的正文内容；
2. **经验沉淀** —— 踩过的坑、定下的执行细则、可复用的做法；
3. **归档指引** —— 已完结线移 `archive/`，事实移 `archive-data.md`，ID 留存防引用悬空。

规则：

- 数据（可核事实）不写在这里，一律进 `DATA.md` 带 ID，本文件只放指针；
- 被上游引用的小节标题改了名，先全文搜引用再改（巡检器 C 组会抓悬空引用）；
- 文件名 = 工作线名，与 `STATUS.md` 热层条目的「细节」字段一一对应。
